TIANA Privacy Notice

TIANA is designed to keep personal money records on the device where they are entered. TIANA's privacy-first release does not send manually recorded balances, income, expenses, transactions, budgets, savings goals, profile name or local coach messages to TIANA's server.

Local device storage

Money records are stored in browser storage on your device. Browser data can be cleared or evicted; export a backup regularly. The local recovery mirror is not encrypted at rest, so use a device screen lock.

Optional usage analytics

Usage analytics are off by default. If enabled in Settings, TIANA receives a random installation identifier and a small set of event names for product usage and installation-level abuse controls. Firebase Analytics, provided by Google, is also enabled and may collect app interactions, app-instance identifiers, device/browser information and diagnostics under Google's privacy terms. TIANA does not send balances, income, expenses, transactions, budgets, savings goals, profile name or money-coach messages to Firebase Analytics or to TIANA's operations database. Turning usage sharing off disables Firebase Analytics collection and requests deletion of the pseudonymous installation and event rows from TIANA's operations database. If the device is offline, deletion is retried after it reconnects. See Google's Privacy Policy.

Push notifications

Push notifications are optional. If enabled, the browser asks for notification permission and sends TIANA a random installation ID and an FCM registration token. TIANA stores that token only to deliver notifications to that installation. You can disable push in TIANA Settings, which removes the server-side token. Push message content is operational app messaging; TIANA must not include a member’s personal balances, income, expenses, budgets or savings records in a push message.

Google Drive backups

When you explicitly request a backup, TIANA encrypts it in your browser with a passphrase before uploading the encrypted file directly to Google Drive app data. TIANA does not receive the file, passphrase or Google access token. TIANA cannot recover a forgotten passphrase.

Network provider metadata

Cloudflare and other network infrastructure providers may process technical request metadata, such as IP address, to deliver and protect the service. TIANA's own operations database does not store IP addresses or personal finance records.
