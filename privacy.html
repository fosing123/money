PRIVACY POLICY

Your money story stays on this device.

This page describes the current static Nkem preview, not a future backend-connected service.

What is stored

Budget entries, amounts, goal details, selected preferences, saved sample listings and other data you enter are stored in this browser using local storage. This preview has no server-side user account and does not send those records to an Nkem database.

Authentication and integrations

Google, email and phone sign-in are not connected. The preview does not connect to a bank, Orange Money, MTN MoMo, payment gateway, live AI model, marketplace seller or investment provider.

External resources

The interface may load web fonts from Google Fonts when you are online. Your browser will connect to that provider to fetch those font resources. Local app illustrations are bundled with the project.

Sharing and safety

Because records are stored in local browser storage, anyone with access to your unlocked browser profile may be able to view them. Avoid entering real passwords, payment information, identity documents or sensitive financial details. JSON exports may contain the data saved in the app; keep exported files private.

Retention and deletion

Data stays in the browser until you reset it in the app or clear the browser's site data. Export a backup first if you need one. Deleting browser data is not a server deletion request because this preview has no user-data backend.

Future versions

Before any production release with accounts, analytics, marketplace messaging, payments or AI integrations, this policy must be revised to describe actual data flows, service providers, security measures, retention periods, user rights and contact details.
